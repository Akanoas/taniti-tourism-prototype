# Taniti Tourism – UX Prototype (D479 / C856)

This repository contains the interactive prototype for the Taniti Tourism website redesign, created for WGU’s D479/C856 UX Design assessments (Task 1 & Task 2). The project includes mid‑fidelity wireframes, guerrilla usability testing results, and a fully interactive HTML/CSS prototype deployed via GitHub Pages.

---

## 🌴 Project Overview
The goal of this project is to redesign the Taniti Tourism website to improve clarity, navigation, and usability for travelers planning a visit to the island. The design focuses on:

- Clear navigation and positional awareness  
- Mobile‑friendly layout  
- Accessible content structure  
- Improved lodging, food, amenities, and transportation information  
- Streamlined user flow from exploration to booking

## 🧪 Usability Tasks (Task 1 Requirement)
These are the five objective usability tasks used for Task 2 peer testing:

1. Find a budget‑friendly lodging option and view its nightly rate.  
2. Locate a restaurant that serves Pan‑Asian food.  
3. Identify the visiting hours for the volcano attraction.  
4. Find the airport shuttle schedule and determine the cost for a family of four.  
5. Navigate to the contact page and submit a booking inquiry.
